# SAY-THIS.md — Copy-and-paste starters for your assistant

**Who this is for:** anyone paired with a Business + Personal Assistant Claw (one human, one assistant).
**How to use it:** find what you want below, copy the line in the grey box, and paste it into your chat with your assistant. Change the details (times, names, topics) to suit you. Your assistant will confirm what it set up — always check the confirmation matches what you meant.

> Tip: mention your **time zone** if timing matters (e.g. "9am UK time" / "9am LA time"). Otherwise it uses the server time zone.

---

## 1. Reminders (one-off)

```
Remind me at 3pm today to call Bryan.
```
```
In 20 minutes, remind me to send the contract.
```
```
Remind me tomorrow at 9am to follow up with the client.
```
```
Remind me on Friday morning to review this week's numbers.
```

## 2. Reminders & jobs (recurring)

```
Every weekday at 9am, give me a short summary of my inbox and calendar.
```
```
Every Monday at 8am, remind me to submit the weekly report.
```
```
On the 1st of each month, remind me to send invoices.
```
```
Every day at 6pm, remind me to log my hours.
```

## 3. Jobs that DO something (not just remind)

```
Every morning at 7am, check the news for anything about our industry and send me a short digest.
```
```
Each Friday at 5pm, summarise what changed this week and message it to me.
```
```
Every Monday, draft a check-in message to my team for me to review.
```

## 4. Managing your scheduled jobs

```
What scheduled jobs do I have?
```
```
Change my 9am inbox summary to 8:30.
```
```
Cancel the Monday report reminder.
```
```
Run my inbox summary now.
```

## 5. Getting help / everyday asks

```
Draft a reply to this email for me to review before sending.
```
```
Summarise this document in five bullet points.
```
```
Remember that my preferred meeting time is mid-morning.
```
```
What do you remember about [project / person]?
```

---

## Good to know

- **Your assistant drafts; you send.** It will write emails, messages, and documents for you, but it does **not** send anything externally or post publicly on its own — you review and send. That's by design.
- **It confirms before it commits.** After you ask for a scheduled job, it tells you exactly what it set (time, frequency, action). Check that, then you're done.
- **Say it in your own words.** You don't need special commands or formatting — plain language works. The boxes above are just starting points.
- **Your context stays yours.** Your assistant is paired to you alone; what it knows about you isn't shared with anyone else's assistant.
