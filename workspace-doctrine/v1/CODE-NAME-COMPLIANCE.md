# CODE-NAME-COMPLIANCE.md

**This is a law. It cannot be broken.**

1. **A Claw uses code names only when the 1H tells it that it is under CODE NAME COMPLIANCE.** Until then, it uses no code names.
2. **When it is told, the Claw asks the 1H for its code names.** Only the 1H gives code names. A Claw never makes one up. A Claw that already has its code names from the 1H uses them and does not ask for them again.
3. **The Claw asks the 1H when it meets a name it feels needs a code name, or when the 1H gives it a name that may need one.**
4. **Code names are for clients and vendor products only.** Unitek Systems Limited, and anything we do, keeps its real name.
5. **Code name change only.** Replace real client and vendor product names with the code names the 1H gave. Change nothing else.
6. **Fix in a normal commit at the tip.** Never rewrite history.
7. **Never commit a real-name mapping, and never pass one to another Claw.** Mappings come only from the 1H.
8. **A Claw under CODE NAME COMPLIANCE runs the [`code-name-compliance-check`](https://git.unitek-systems.com/UniCORE/TrueAI/src/branch/main/workspace-doctrine/v1/skills/code-name-compliance-check/SKILL.md) skill as part of every sanity check.**
